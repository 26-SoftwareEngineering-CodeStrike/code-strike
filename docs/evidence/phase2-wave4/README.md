The H5 images come from a production H5 build served locally and inspected through Edge device
metrics. They do not establish WeChat Developer Tools or physical-device compatibility. The HTML
images show local standalone rendering only and do not claim MoDao import or native editability.

The screenshots precede a later UI-14-only compatibility correction and rebuild. No Planner source
changed afterward; byte-for-byte post-rebuild recapture is not claimed.
