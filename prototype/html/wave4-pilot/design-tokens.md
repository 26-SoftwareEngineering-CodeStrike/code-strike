# Standalone design tokens

| Token | Value | Use |
| --- | --- | --- |
| Ink | `#14213d` | Primary text |
| Ink soft | `#344054` | Supporting product text |
| Blue | `#2563eb` | Primary actions and active guidance |
| Lime accent | `#c9f43d` | CodeStrike mark and active navigation icon only |
| Canvas | `#f5f7fa` | Page background |
| Surface | `#ffffff` | Cards, inputs and navigation |
| Surface soft | `#eef3f8` | Selected and secondary surfaces |
| Muted | `#667085` | Secondary copy |
| Subtle | `#8993a4` | Metadata |
| Line | `#dfe4ea` | Borders |
| Success | `#16856b` | Open/positive state with a text label |
| Mobile gutter | `16px` | Shared content alignment at 320-430px |
| Touch target | `44px minimum` | Primary interactive controls |
| Corner radius | `7-18px` | Status labels, controls and cards by hierarchy |

The pages use the local system sans-serif stack and have no external font or image dependency.
Typography follows the D1 scale: 12-13px metadata, 15-16px body, 18-21px section titles and
22-28px page goals. Ordinary cards use borders rather than decorative shadows; the floating
bottom navigation is the only elevated surface.
