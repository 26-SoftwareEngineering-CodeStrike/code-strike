# Standalone design tokens

| Token | Value | Use |
| --- | --- | --- |
| Ink | `#071a35` | Primary text |
| Navy | `#0b1c38` | Hero and dark surfaces |
| Blue | `#2c61d4` | Primary action / matched state |
| Lime | `#d6ff65` | High-emphasis action |
| Mint | `#d8f8ef` | Positive status |
| Paper | `#f3f6f9` | Page background |
| Muted | `#687a94` | Secondary copy |
| Line | `#d9e2ec` | Borders |
| Corner radius | `14–30px` | Controls, cards and hero |

The pages use the local system sans-serif stack and have no external font or image dependency.
